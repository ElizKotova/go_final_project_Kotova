# Планировщик задач (Task Scheduler)

## Описание проекта

Это веб-приложение представляет собой планировщик задач с веб-интерфейсом. Пользователи могут создавать, редактировать, удалять и отмечать задачи как выполненные. Приложение поддерживает повторяющиеся задачи с различными правилами повторения.

## Функциональность

- Создание, редактирование и удаление задач
- Отметка задач как выполненных
- Поддержка повторяющихся задач (ежедневно, еженедельно, ежемесячно, ежегодно)
- Поиск задач по ключевым словам или дате
- Аутентификация пользователей через JWT токены
- Хранение данных в SQLite базе данных

## Выполненные задания со звездочкой

- Поддержка переменной окружения `TODO_PORT` для настройки порта сервера
- Поддержка переменной окружения `TODO_DBFILE` для настройки пути к файлу базы данных
- Реализация правил повторения задач (d, y, w, m)
- Поиск задач по заголовку, комментарию или дате
- Создание докер-образа с веб-сервером

## Инструкция по запуску кода локально

### Требования

- Go 1.24 или выше
- SQLite

### Запуск приложения

1. Склонируйте репозиторий:
   ```
   git clone https://github.com/ElizKotova/go_final_project_Kotova
   cd go_final_project_Kotova
   ```

2. Инициализируйте модуль Go:
   ```
   go mod tidy
   ```

3. Запустите приложение:
   ```
   go run main.go
   ```

4. Откройте в браузере: http://localhost:7540

### Переменные окружения

- `TODO_PORT` - порт для запуска сервера (по умолчанию 7540)
- `TODO_DBFILE` - путь к файлу базы данных (по умолчанию scheduler.db)
- `TODO_PASSWORD` - пароль для аутентификации (если не задан, используется пароль по умолчанию "user")
- `JWT_SECRET` - секрет для подписи JWT токенов (по умолчанию "default_secret")

### Пример запуска с аутентификацией

В Windows (Git Bash):
```
export TODO_PASSWORD=12345
export JWT_SECRET=my_secret_key
go run main.go
```

В Windows (Command Prompt):
```
set TODO_PASSWORD=12345
set JWT_SECRET=my_secret_key
go run main.go
```

В Linux/macOS:
```
TODO_PASSWORD=12345 JWT_SECRET=my_secret_key go run main.go
```

Пример файла .env:
```
TODO_PORT=7540
TODO_DBFILE=scheduler.db
TODO_PASSWORD=12345
JWT_SECRET=my_secret_key
```

## Инструкция по запуску тестов

Перед запуском тестов убедитесь, что сервер не запущен на порту 7540, или измените порт в файле [tests/settings.go].

1. Запустите сервер:
   ```
   go run main.go
   ```

2. В другом терминале запустите тесты:
   ```
   go test ./tests -v
   ```

Также можно запустить все тесты одной командой:
```
go test ./tests/... -v
```

### Настройка тестов

В файле [tests/settings.go] можно настроить:
- `Port` - порт сервера (по умолчанию 7540)
- `DBFile` - путь к файлу базы данных (по умолчанию "../scheduler.db")
- `FullNextDate` - флаг для тестирования расширенных правил повторения (по умолчанию: false)
- `Search` - флаг для тестирования поиска (по умолчанию: false)
- `Token` - JWT токен для аутентифицированных запросов (если аутентификация включена)

## Инструкция по сборке и запуску через Docker

### Сборка Docker-образа

```
docker build -t todo-scheduler .
```

### Запуск контейнера

Без аутентификации:
```
docker run -d -p 7540:7540 -v $(pwd)/scheduler.db:/root/scheduler.db --name todo-scheduler todo-scheduler
```

С аутентификацией:
```
docker run -d -p 7540:7540 -e TODO_PASSWORD=12345 -e JWT_SECRET=my_secret_key -v $(pwd)/scheduler.db:/root/scheduler.db --name todo-scheduler todo-scheduler
```

### Переменные окружения в Docker

- `-e TODO_PORT=7540` - порт сервера
- `-e TODO_PASSWORD=12345` - пароль для аутентификации
- `-e JWT_SECRET=my_secret_key` - секрет для JWT токенов
- `-v $(pwd)/scheduler.db:/root/scheduler.db` - монтирование файла базы данных

После запуска контейнера откройте в браузере: http://localhost:7540
